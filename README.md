# e-plantShopping

## Paradise Nursery – React Shopping App

### Overview

This project is the final assignment for the React course in the IBM Full Stack Software Developer specialization.

The application is a front-end shopping experience for a fictional plant store called Paradise Nursery. Users can browse houseplants, add them to a shopping cart, adjust quantities, and view the total cost before checkout.

The project demonstrates practical use of React components, state management, conditional rendering, and dynamic UI updates.

<br>

## Features

### Landing Page

- Background image

- Company name and description

- “Get Started” button that navigates to the product listing page

### Product Listing Page

- At least six houseplants

- Organized into three or more categories

- Each plant includes:

1. Thumbnail image

2. Name

3. Price

4. “Add to Cart” button

- Header with:

1. Navigation

2. Shopping cart icon

3. Dynamic item counter

<br>

## Shopping Cart Page

- Displays all items added to the cart

- Shows:

1. Plant thumbnail and name

2. Unit price

3. Quantity

4. Total price per item

- Allows:

1. Increasing quantity

2. Decreasing quantity

3. Removing items

- Displays:

1. Total number of items

2. Total cost

- Includes:

1. Continue Shopping button

2. Checkout button

- Shopping cart icon updates dynamically
